## Production rule
The supplied screen is a JPEG/raster reference. For a production UI:
1. Recreate text, buttons and layout as native Figma/code components.
2. Rebuild simple icons as SVG.
3. Keep the soft map illustration as optimized WebP/PNG unless it is professionally redrawn.
4. Use Figma Variables for the shared token system.
5. Use one shared component library across Collector App, Recycler Web and Admin Web.
