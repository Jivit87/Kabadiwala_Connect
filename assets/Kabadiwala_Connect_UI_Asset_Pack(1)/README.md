# Kabadiwala Connect — UI Asset Pack

This pack is extracted from the supplied splash-screen reference and organized for Figma/UI work.

## Included
- Brand logo lockup and mark
- Transparent-style logo/hero variants
- Splash hero illustration crop
- Three feature icon crops
- CTA crop
- Design tokens / palette
- Asset manifest

## Important
The supplied image is a raster reference. For production-quality UI, the logo and hero illustration should be rebuilt/vectorized rather than repeatedly scaling the PNG. The raster assets are intended for visual matching and Figma reference work.

## App direction
- Mobile-first, large touch targets
- Warm off-white surfaces
- Deep green primary actions
- Icon + text + audio for low-literacy flows
- Hindi/Marathi/English localization
- Offline states visibly represented

## Web direction
- Same brand tokens and illustration language
- More compact information density
- Data tables, cards, filters, charts and status badges
- Use SVG icons/components rather than screenshot crops
